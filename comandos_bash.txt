Comandos GitBash:

ls -> lista de pastas / ls -a - arquivos ocultos
cd -> muda o diretorio
	Desktop/ - abre a area de trabalho
pwd -> mostra o caminho
.. -> volta no diretorio
mkdir -> cria uma pasta nova no diretorio
cat -> abre um arquivo
git init . -> transforma em uma pasta do git
rm -rf .git/ -> exclui a pasta git para tornar uma pasta normal - CUIDADO!!!!!
rm -> remove arquivo ou diretório


Comandos Git:

git status -> status da pasta
git add <file> -> é o que quero que vá para o commit
git commit -m "mensagem de texto" -> pra fazer o commit
